# EHTL Beneficios

Prototipo interno de controle de beneficios para o RH da EHTL Viagens. Esta primeira etapa usa somente dados ficticios e armazenamento em memoria.

## Executar localmente

Nao e necessario instalar Node.js, Python ou iniciar um servidor. Abra o arquivo `index.html` diretamente no navegador, por duplo clique.

O prototipo funciona sem backend e usa somente dados ficticios em memoria. Nao use dados reais nesta versao.

## Primeira etapa

- Dashboard com metricas, pendencias, custo estimado e aniversariantes.
- Cadastro de colaboradores com busca e filtro por departamento.
- Beneficios com estimativa de VR/VT por jornada, admissao, desligamento e atestado.
- Navegacao preparada para Dependentes, Atestados, Competencias, Relatorios e Configuracoes.

O desenho completo da arquitetura, banco futuro, regras e integracoes esta em [docs/ARQUITETURA.md](docs/ARQUITETURA.md).
